## 🚀 项目经验  

### 选址地图（Vue3 + L7 + 高德地图）  
**技术栈**：L7 DistrictData、 
**项目介绍**：  
1. 概览模式
 - 全国、省、市、区 纬度展示门店分布信息
 - 全国、省、市通过面的颜色深浅来表示门店多少的对比
 - 可上钻下钻，级别之间互相切换
 - 通过多选门店类型，动态展示当前选择的数据
 - 查看当前市、区点位信息，查看门店详情（门店照片、数据看板、巡店信息等）

2. 选址模式
 - 商圈、商场、门店之间根据放大缩小zoom动态切换，也可通过点击进行切换
 - 点位信息由 围栏Polygon 点位Marker 组成
 - 可以搜索，跳转到指定级别
 - 可以收藏点位信息
 - 最后一级是门店，点击后可查看详情，同概览模式门店详情

3. 自动获取位置信息，定位当前位置
4. 都有省市区筛选
5. 导航到指定门店

**技术实现**：
1. 使用谷歌地图的`amap-js-api 1.4.16`进行渲染选址模式
 - 最新为2.0,但是通过调研与demo测试，发现2.0适配不如1.4.16兼容高、2.0在ios低版本上有卡顿现象
 - getBounds() 下 getSouthWest() getSouthEast() getNorthEast() getNorthWest()  获取当前地图可视区经纬度查询
2. AMapLoader.reset() 清理地图,不然无法切换版本
3. 动态清除可视区域外的围栏点位信息，视野外围内的围栏点位信息做缓存处理，不删除重新渲染，防止浪费性能
4. 海量数据卡顿解决:设置可视范围内 最大渲染量，视角范围大时，渲染点位不渲染围栏，小而多时，设置渲染上限,渲染中心点附近点位信息
5. 概览模式使用 阿里L7地图, 适配性高、速度快
  - 动态配置regl渲染模式和 webGL渲染模式, 适配低版本机型 
  - 使用线性渐变色渲染，动态设置色值最大值，保证颜色差的准确性
6. 使用 `DistrictData SDK `获取行政区划数据，加载数据更快，效果好

### 组织架构系统（权限管理系统）（Vue2 + element-ui）  
**项目介绍**：  
1. 门店、部门、岗位、角色、用户管理，支持增删改查，支持树形结构管理, 支持拖拽
  - 角色可分配平台权限和资源权限
  - 岗位可分配 默认角色
  - 用户可分配 多岗位、多角色、多部门、以及自定义数据权限
  - 数据权限分不同维度: 所在部门、城市、门店类型
2. 资源管理、平台管理，支持增删改查，支持树形结构管理
 - 资源管理可配置: 按钮、菜单权限
 - 平台管理可配置: 平台名称和平台对应链接是否校验权限等
3. 入职离职管理
  - 入职自动开通企微、工作账号等
  - 离职自动解绑企微、工作账号。选择继承企微客户等
4. 培训管理
 - 生成培训表单页面,录入培训人员信息
 - 培训结束后可根据培训表单信息加入到候选人列表中
 - 确认候选人信息无误后，可加入到人员列表
**技术实现**:

1. 树形结构组件懒加载，动态更新树结构，减少内存占用，加快页面渲染速度

2. 使用 Vue.directive 注册自定义指令，实现按钮权限控制

3. 使用 vue-router 配置路由，addRouter 动态添加路由,实现菜单权限控制
